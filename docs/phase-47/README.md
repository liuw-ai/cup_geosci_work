## 发布门禁

只有 `government_position_registry.json` 中 `verified_open` 且 `explicit_match` 的岗位由 worker 同步到正常岗位索引。附件解析候选仍停留在管理员复核队列；来源故障或截止岗位不会被写成当前无岗位。
