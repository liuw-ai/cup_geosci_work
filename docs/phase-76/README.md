# Phase 76：生产审计修复与中石化官方快照恢复

## 目标

本阶段处理上一阶段上线审计的两个真实阻塞：

1. 中国地质调查局岗位的官方详情域名 `www.drc.cgs.gov.cn` 未被生产审计识别为白名单主机；
2. 中国石化 132 个单位快照超过 30 小时新鲜度门禁，不能继续使用旧快照冒充当日数据。

## 实现

- 审计主机集合现在同时读取来源的 `allowed_hosts`、`detail_allowed_hosts` 和 `attachment_allowed_hosts`；
- CGS 来源注册表将 `www.drc.cgs.gov.cn` 纳入运行白名单；
- 服务器两个隔离 Chromium 内核容器按当前 Compose 配置重建，消除旧容器重复 CDP 参数导致的 9222 端口冲突；
- 通过服务器 Chromium 的官方只读 SPA 接口重新捕获中石化单位清单和候选单位详情；
- 新快照 `data/verified/sinopec-geoscience-20260929.json` 确认 132 个单位、35 个候选单位、363 条岗位行，所有候选单位分页完成且失败行为 0；
- 来源配置切换到新快照，旧快照保留为历史证据，不覆盖、不删除；
- 增加详情域名审计回归测试和最新快照完整性回归测试。

## 明确边界

本阶段恢复的是“受控官方快照”而不是每日自动抓取器。快照仍受 `max_age_hours=30` 门禁约束；下一阶段必须把同样的 API/浏览器捕获流程做成独立的服务器 Worker，成功捕获后才可宣称每日更新链路打通。

## 进入下一阶段条件

1. 生产数据库审计 `ok: true`；
2. Worker、备份和正式域名分别通过各自健康检查；
3. 中石化快照在 30 小时内重新捕获并通过 `--require-complete --require-scan-complete`；
4. 新增的省级事业编、公务员职位表仍须沿用官方附件、岗位行和报名窗口门禁。
