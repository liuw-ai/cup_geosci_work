# Phase 84 国聘部分捕获保护

国聘动态招聘页面的“部分抓取”不是岗位消失，也不是“扫描成功无匹配”。在服务器实测中，分页已完成但少数官方详情页会超时或浏览器渲染进程中断。若让该结果覆盖正式快照，下一次同步会失去最后一份完整的官方岗位级证据。

本阶段将正式捕获路径定义为 success-only：只有状态为 `success` 且分页、列表和详情计数全部完整时，才能原子替换该路径。`partial`、`access_limited` 和 `parse_failed` 均写入与正式快照同级的带时间戳 `*.failures/` 目录，同时更新一个仅供运维查看的 `*.failure.json` 最新诊断副本。两者都不会被学生端来源读取。

失败归档保留本次分页计数、已成功读取的官方详情行、每个失败详情的页码、卡片标识、详情链接和失败原因。没有历史成功快照时，部分结果也只会创建失败归档，不会创建伪装成可发布来源的正式文件。

## 运维影响

- 无数据库迁移、无数据回填、无学生端岗位变化。
- 服务器升级后，`cmgb-browser` worker 下一次运行自动使用新规则；不要手工把 `*.failure.json` 或 `*.failures/` 内文件复制为正式捕获文件。
- 正式动态来源仍保持停用，只有完整捕获通过 `cmgb-production-transition` 的既有专业、学历、地点、人数、截止日期和学生画像门禁后才允许接管已审阅快照。

## 验收

回归测试覆盖：成功快照后的部分结果不覆盖正式文件；失败详情证据写入归档；没有成功历史时部分结果不创建正式快照；标记为成功但计数不完整的结果被拒绝写入。
