# Phase 11：国内官方岗位采集突破

本阶段直接处理项目当前最关键的缺口：国内正式岗位来源少、学校就业网列表过早截断、同一公告中的多个岗位被压成一条、政府站点常用 `.xls` 职位表无法进入审核链路。

## 目标

- 只从单位官网、政府官网和正式招聘栏目增加可回溯岗位。
- 把一份公告中的独立岗位拆成可检索记录，同时共享同一官方原文证据。
- 让官方 PDF/Excel（包括传统 `.xls`）先进入管理员候选队列，再由人工核验后发布。
- 用真实运行结果区分“扫描成功但本次没有开放匹配”“公告已过期”和“来源访问故障”。

## 本阶段交付

1. 修复 HTML 招聘公告正文误过滤：标题中的“拟录用/采购”等后续流程词仍会排除，正文中出现“拟录用人员”不再误删真实招聘公告。
2. 增加配置驱动的公告拆岗适配器，并接入中国冶金地质总局地球物理勘查院官方招聘页：实际新增 6 条岗位记录，均保留 `geoexp.cn` 原文链接。
3. 增加官方 `.xls` 解析：支持传统 BIFF、扩展名误标但内容为 OOXML 的文件、多行表头和合并单位向下填充。
4. 真实处理安徽省地质矿产勘查局公告中的官方职位表：22 行进入私有审核候选，人工核验其中 2 行后发布，非目标专业行仍未公开。
5. 修正同一公告拆成多个岗位后的审计规则：只有来源显式设置 `allow_shared_source_url` 时才允许共享原文链接，真正的重复岗位仍会被拦截。
6. 修正中国石油大学（北京）就业网适配器：列表页只作发现，扩大候选窗口；详情页采用明确专业证据，避免正文中的门户导航词误删真实公告，并识别招聘账号与实际用人单位的差异。
7. 串行复测中国地质调查局、自然资源部、中国冶金地质总局、中国煤炭地质总局及已启用的省级来源，并把结果写入运行快照。

## 当前边界

本阶段没有绕过 robots、403、412、验证码、登录或 WAF，也没有把第三方聚合平台、公众号内容直接公开。中国石油、中国石化、国家管网等统一入口的访问限制仍记录为来源故障；后续只能从其下属单位公开公告、职位表或人工核验的官方原文继续扩展。

“岗位总数”仍不是验收唯一指标。阶段报告同时记录来源活跃度、字段完整率、来源集中度、明确专业匹配数和审核候选数。
