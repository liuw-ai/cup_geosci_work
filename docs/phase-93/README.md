## 生命周期门禁

中国地震局 2027 年事业单位职位表的 91 条明确匹配岗位报名时间为 2026-10-10 至
2026-10-26。新增回归测试证明：

1. 2026-10-09 仍只出现在“即将开放”，不计入在招数量；
2. 2026-10-10 起，在官方证据复核成功且未过期时自动进入当前岗位；
3. 2026-10-27 起全部自动退出当前岗位。

这保证了后续 worker 只需完成官方证据复核，不需要人工修改岗位状态，也不会把历史
职位表当成当年度在招岗位。
