## 本阶段目标

把已登记的三份省级自然资源/地质系统官方职位表从“服务器待下载”推进到受控下载、哈希留存、表格行提取和私有复核队列：

- 山东省地质矿产勘查开发局 2026 年事业单位岗位表；
- 河南省地质局 2026 年事业单位公开招聘联考岗位表；
- 天津市规划和自然资源局所属事业单位 2026 年招聘计划表。

所有岗位仍以政府官网公告页和官方附件为证据。第三方汇总、公众号和教辅平台不参与发布。
