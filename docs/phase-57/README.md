# Phase 57: 政府职位台账生产新鲜度与逐来源清退

本阶段不新增未经核验的岗位，专门修复事业编、博士后和未来公务员职位表在生产环境中的生命周期问题：

- 官方职位表台账现在有明确的新鲜度门禁，默认 `48` 小时；
- 台账超过门禁后，岗位不再继续展示，等待管理员重新核对官方公告/附件并更新 `as_of`；
- 每次 worker 同步按政府来源和稳定外部编号执行撤回，截止日期、岗位表变更和来源快照过期都会被清退；
- 缺少来源注册属于配置故障，不会被误判为“扫描成功无岗位”，也不会盲目清除旧数据；
- 审计报告新增 `registry_age_hours`、`registry_freshness` 和门禁阈值，便于管理员确认每日更新是否真正发生。

当前真实台账基线（2026-09-28）：

- 136 条逐岗位官方证据；
- 122 条当前明确匹配岗位，14 条已关闭；
- 7 个政府/科研来源，12 个来源评估；
- 地质学、地质资源与地质工程、地质工程、资源勘查等专业证据完整率 100%；
- 当年度公务员岗位仍为 0，因为尚未确认官方当年度职位表，不导入历史数据。

本阶段的目标是防止旧岗位永久滞留，不把“岗位数量”当作质量替代品。
