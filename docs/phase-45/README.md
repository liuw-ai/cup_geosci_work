## 外部待办

域名注册商仍需添加：`A` 记录，主机名 `jobs`，值 `81.70.62.174`，TTL 约 600 秒。
该操作需要注册商账号权限，服务器和代码无法代替域名服务商写入 DNS。记录生效后在
服务器执行：

```bash
cd /opt/cup_geosci_work
docker compose exec -T web python -m job_hub.cli domain-check \
  --hostname jobs.cupdky.cn --expected-ip 81.70.62.174
```

只有 `ready=true` 且从公网完成 HTTPS 健康检查，才可把域名链接发给学生。
