# Phase 46：政府职位表 PDF 布局解析与甘肃附件回归

本阶段继续服务中国石油大学（北京）地球科学学院学生，目标是把事业单位和公务员
官方职位表中的真实岗位稳定送入“私有候选 -> 人工核验 -> 学生端”链路。它不以历史
岗位增加当前数量，也不把解析成功当成发布成功。

## 本阶段完成

- 甘肃省地矿局 2026 年官方公告和 PDF 职位表纳入政府附件台账；公告计划 23 人，报名
  期为 2026-08-24 至 2026-09-01，当前已截止。
- PDF 优先使用 `pypdf` 的 `layout` 提取模式，保留职位表的视觉列关系；旧版依赖不支持
  该参数时安全回退到普通文本提取。
- 以职位代码为行边界聚合跨行文本，并保留页码、行号、原始行文本和附件 URL 作为证据。
  解析器只产生私有 `needs_review` 候选，不绕过专业、学历、地点、截止日期和人工核验门禁。
- 为职位代码、岗位名称、学历和地学专业增加保守字段提示；无法识别的列仍保留原始文本供
  管理员复核，不能因为字段不完整而伪造岗位。
- 已有过期清退逻辑继续生效：甘肃地质岗位只用于历史证据和解析回归，不进入当前学生端。

## 当前真实结论

甘肃 PDF 中可以识别出 `202602104`、`202602201`、`202602103` 等地质技术人员岗位，
其中包含资源勘查工程、矿产普查与勘探、环境地质工程等专业要求；但报名期已结束，
因此当前政府公开岗位仍只有安徽 2 条明确匹配。数量没有用历史岗位充数。
