# Phase 41：附件候选过期清退门禁

## 目标

让每日同步同时维护公开岗位和私有附件复核队列。截止日期早于服务器本地业务日期的附件候选会被标记为 `expired`，不再占用待复核队列，也不会被误认为当前机会。

## 行为

- 只处理 `needs_review` 和 `official_content_verified` 候选；已发布候选不被修改。
- 仅依据岗位行中的明确 `deadline_date` 清退，缺失截止日期的候选继续留在人工复核队列。
- 不删除数据库记录、原始附件、内容哈希、表名、行号或字段证据。
- 每次 worker 同步都会执行一次，幂等重复运行不会重复追加系统备注。

## 自检结果

- 本地全量测试：`275 passed`
- 服务器现有附件：安徽 22 行、山东 48 行、河南 54 行、天津 54 行均已下载并解析；山东、河南、天津报名截止日期已过，因此不会进入学生端。
- 安徽官方岗位表中 2 条地学博士岗位已发布并保留官方公告与附件行证据；其余非目标专业行仍在私有队列。

## 边界

过期清退不代表来源扫描成功无匹配，也不改变来源故障状态。访问受限、附件下载失败、未注明截止日期仍分别保留原状态，日报中继续区分“过期”“待核验”和“来源故障”。
