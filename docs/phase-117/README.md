# Phase 117: Geophysics eligibility taxonomy

## Why this phase exists

The student publication gate previously covered resource exploration
engineering, geology, geological engineering and geological resources and
engineering, but it had no first-class profile for geophysics. Official rows
that explicitly required geophysics, solid-earth geophysics or geophysical
logging could therefore remain in review even when the degree and row-level
evidence were complete.

This phase adds the Ministry of Education-aligned geophysics record (0708,
undergraduate code 070801) and undergraduate, master's and doctoral profiles.
It does not make related fields such as geophysical exploration or seismic
engineering exact matches unless the official row also names an accepted
geophysics term. The existing evidence-scope, degree and experience gates
remain unchanged.
