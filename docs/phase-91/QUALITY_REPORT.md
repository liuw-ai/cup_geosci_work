# Phase 91 质量报告

## 已完成

- `official_snapshot_rows` 支持 `max_age_hours` 与 `snapshot_captured_at` 契约；启用新鲜度时缺少时间戳、时间戳无时区、未来时间和过期快照都会失败关闭。
- 过期快照以 `SourceSkipped` 记录来源问题，不撤回旧的已核验岗位，也不产生“扫描成功但无岗位”。
- CNPC、国家管网生产快照配置为 30 小时门禁；服务器手动同步结果分别为 `official snapshot is stale`，证实门禁生效。
- 国聘详情重试最多 3 次，使用新页面隔离每次尝试；访问策略限制不重试。
- 浏览器 Dockerfile 支持缓存基础镜像和显式复制当前 `job_hub` 代码，减少服务器重复下载依赖导致的部署中断。
