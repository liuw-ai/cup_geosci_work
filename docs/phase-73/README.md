# Phase 73：中国地质调查局动态招聘来源适配

## 目标

把中国地质调查局移动招聘栏目从“空 HTML 壳”接入官方 JSON 列表和详情页，同时保持学生端的真实性门禁：列表命中不等于岗位发布，只有详情页中的招聘语义、地学专业证据、学历和官方详情链接经过现有流水线后，才可能进入公开岗位库。

## 关键实现

- 注册 `cgs_dynamic_json` 来源类型；
- 读取 `news_4288.json` 及有界分页 `news_4288_{page}.json`；
- 排除列表末尾 `load more` 哨兵、拟聘/资格审查等非岗位公告；
- 对详情链接执行官方域名白名单校验；
- 从详情正文提取专业要求、学历要求、地点和招聘人数，并保留公告标题、列表日期和详情 URL；
- 让动态来源与官方附件发现共用同一列表过滤器；
- 动态 JSON 或详情失败仍作为来源故障/空结果处理，不伪造“无岗位”。

本阶段只扩展一个真实官方来源适配器，不宣称已经完成全国事业编、公务员或三桶油大规模扩容。
