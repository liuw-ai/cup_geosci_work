## 新增门禁

1. `status` 必须是 `success`；`partial`、`access_limited` 和 `parse_failed` 不得发布。
2. `pagination_complete` 必须为真，且导出行数必须等于发现行数。
3. 每个详情页都必须成功，详情失败不能转成“扫描成功无匹配”。
4. 每条记录必须有专业、学历、地点、招聘人数、截止日期、官方详情链接和字段证据。
5. 详情与证据 URL 必须属于登记的官方域名；重复岗位编号拒绝加载。
6. 捕获超过 30 小时自动判定为过期；过期捕获不会覆盖新的学生端数据。
