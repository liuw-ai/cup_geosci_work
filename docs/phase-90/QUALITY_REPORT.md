# Phase 90 质量报告

## 代码验收

- 连续失败计数与历史尝试次数分离；
- 普通失败和访问策略限制使用不同退避上限；
- 成功后连续失败计数归零；
- 旧数据库可通过加列迁移；
- 现有失败状态和公开岗位门禁不改变；
- 新增队列、迁移和退避回归测试。

## 真实性边界

本阶段没有新增岗位数量，也没有把 `source_unavailable`、`access_limited` 或 `parse_failed` 转换成无岗位或开放岗位。它只提高来源运行的稳定性；国内岗位扩容仍必须逐来源完成官方详情和字段证据核验。
