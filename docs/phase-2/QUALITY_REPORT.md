## 真实来源边界

版本库中已有的真实官方来源注册表包括中国石油大学（北京）就业信息网、中国地质调查局、自然资源部所属企事业单位公开招聘平台、中国煤炭地质总局及其他已核验来源。本阶段没有声称这些来源已经新增附件岗位，也没有用第三方聚合页面填充数据；实际附件处理必须在管理员逐条确认公告页和附件链接后执行。

自动化测试使用本地生成的临时表格和受控响应，只证明代码的安全边界与数据流，不构成公开招聘样例。

`pyflakes` 仍报告少量 Phase 1 遗留的未使用导入（`matching.py`、`pipeline.py` 和两个测试文件）；本阶段未新增此类报告，未借机扩大范围清理。

## 未完成事项

- 尚未批量扫描 31 省或三桶油单位矩阵；Phase 2 是附件基础设施，不是扩源阶段。
- DOC/DOCX、旧式 XLS 和复杂 PDF 表格的解析能力取决于依赖和文件结构；无法稳定解析时会进入人工核验，而不是猜测字段。
- OCR 结果没有自动发布权限；管理员仍需打开原公告和原附件核对。
- 当前没有管理员可视化后台，管理操作使用受保护 API/CLI；后台 UI 属于后续阶段。
- 本次没有对外部招聘站点做批量网络回归，避免把未经逐站准入的域名误当成可抓取来源。
