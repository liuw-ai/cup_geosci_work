# Phase 21：国家管网岗位级详情链接与字段展示

本阶段只处理国家管网官方校园招聘“地质”筛选结果的岗位级可达性，不把动态页面的搜索结果误当成单一招聘入口。

## 已完成

- 对官方搜索结果中的 24 条岗位逐条核对岗位编号和下属单位编号。
- 为 24 条岗位生成官方 `common_board_view_anonymous` 详情链接，详情页能够显示对应岗位和正确下属单位。
- 登记官方“地质”筛选入口 `search_key=地质`，作为详情页打不开时的备用入口。
- 将招聘人数、职位类别、职位序列、官方下线时间、岗位编号和筛选入口写入岗位级证据。
- 学生端详情页展示招聘人数等字段，继续执行既有专业和学历发布门禁。

## 真实性边界

编号索引来自国家管网公开招聘列表和详情页的浏览器核验，不绕过登录、验证码或访问策略。详情页仍以国家管网官方原文为准；快照更新时必须重新核对编号和单位编号。

## 未完成事项

当前仍是版本化官方快照，尚未实现服务器直连动态接口的自动同步。后续需在服务器合规网络中复测，并保留失败单位为访问受限，不把失败响应改写成无岗位。
