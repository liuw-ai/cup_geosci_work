# Phase 0 审阅包：治理基线

本目录是地学就业信息站长期迭代的第一个审阅包。它不新增任何招聘来源、不修改学生端页面，也不改变运行数据库中的岗位数据。它的作用是把后续每一次扩源、解析和发布所必须遵守的业务边界写清楚，避免岗位数量增加后出现来源不明、专业误匹配或无法回退的问题。

## 本阶段范围

- 明确服务对象、就业范围、公开信息边界和非目标。
- 固定岗位分类、单位体系分类和专业匹配术语。
- 建立来源准入、停用、复核和发布的规范。
- 设定后续版本必须报告的质量指标和验收门槛。
- 冻结当前运行库的只读基线，作为后续改善的比较起点。

## 本阶段不做什么

- 不新增或启用任何爬虫来源。
- 不绕过 robots.txt、登录、验证码、访问控制或网站使用规则。
- 不将公众号、教辅机构、行业媒体或招聘聚合站的信息直接公开给学生。
- 不迁移数据库、不删除岗位、不重新发布日报，也不改变现有页面样式。

## 审阅顺序

1. 阅读 [项目契约](PROJECT_CONTRACT.md)，确认服务对象、岗位范围和公开承诺。
2. 阅读 [来源准入规范](SOURCE_ADMISSION_POLICY.md)，确认“可发现”与“可公开”的边界。
3. 阅读 [验收指标](ACCEPTANCE_METRICS.md)，确认后续版本如何证明质量真的提高。
4. 阅读 [当前基线报告](BASELINE_2026-09-20.md)，确认当前的真实短板。
5. 使用 [阶段审阅清单](REVIEW_CHECKLIST.md) 给出“通过”或需要修改的业务规则。
6. 阅读 [交付说明](DELIVERY_NOTES.md)，核对本阶段的变更范围、数据库影响和测试结果。

## 版本与回退

本审阅包从 `v0.3.0` 对应提交 `1d28b3f` 建立。Phase 0 的实现工作在独立分支 `phase/0-governance-baseline` 中进行；合并前不改变 `master`。通过审阅后，Phase 0 将以新的 Git 提交和标签固化，后续阶段均从已审阅的标签开始。
