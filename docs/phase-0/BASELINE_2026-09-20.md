## 已识别的优先风险

1. 国内官方来源覆盖不足，外企标准 ATS 结果在当前池中占主导。
2. PDF、Excel 和扫描件职位表尚未形成受控下载、解析、证据定位与人工复核流水线。
3. 省份、截止日和单位层级字段的完整度不足，尚不适合用“全国全覆盖”对外表述。
4. 最近日报为 2026-09-18，需在后续运行阶段查明 worker/服务重启后的调度与报告新鲜度问题。
5. 100 人模拟适合发现覆盖空白，但不适合作为岗位丰富度或就业成果的单一指标。

## Phase 0 结论

当前系统已具备正确的公开证据、来源健康、日报快照和私有线索隔离方向，但尚不具备大规模、国内、行级、可核验职位表采集能力。Phase 1 应先把单位、来源、岗位、证据和状态的结构化契约补齐；在此之前，不应为了增加岗位数量而降低官方原文或专业证据标准。
