# 项目契约

## 1. 服务对象

本项目只面向中国石油大学（北京）地球科学学院学生，优先服务以下七种匿名学历与专业画像：

| 学历 | 专业 |
| --- | --- |
| 本科 | 资源勘查工程 |
| 硕士 | 地质学、地质工程、地质资源与地质工程 |
| 博士 | 地质学、地质工程、地质资源与地质工程 |

网站不保存学生姓名、学号、简历、联系方式、浏览画像或投递记录。画像筛选只用于当前请求的解释性过滤，不能被用作个人数据建档。

## 2. 产品承诺

学生可通过一个公开 HTTPS 链接在手机、微信或电脑浏览器中查看当前在招岗位和每天冻结的就业日报，无需安装 App、登录或提交个人资料。每条公开岗位必须让学生能够看到招聘主体、岗位名称、来源、时效状态和官方原文入口。

系统承诺“可验证覆盖”，不承诺无法证明的“全网零遗漏”。具体含义是：

- 已登记来源的健康状态、最近扫描结果和覆盖缺口可被管理员审计。
- 已公开岗位能够回溯到单位官网、政府官网、高校/科研院所官网或正式招聘系统。
- 来源故障、未定位、访问受限和解析失败不能被展示为“当地没有岗位”。
- 岗位越多，公开证据要求不降低。

## 3. 收录范围

全国范围内的正式公开机会均可进入核验流程，包括校招、社招、实习、博士后、科研助理、人才引进、事业单位、公务员、选调和明确适配专业的不限专业岗位。国内在华外企、国际岗位、银行及其他央国企综合机会，在原公告明确适配或不限专业时同样可以收录。

优先行业和单位体系如下：

| 就业路径 | 说明 |
| --- | --- |
| 油气勘探开发运营单位 | 资源权属、勘探开发和生产运营主体，不以“业主”作为学生端笼统标签。 |
| 集团内研究院与科研机构 | 勘探开发、地学、油气藏、地球物理、测井及相关研究单位。 |
| 集团内工程技术与油田服务单位 | 物探、测井、钻井、录井、完井、地面工程等集团体系内单位。 |
| 独立、民营与国际油田服务单位 | 与集团内部服务单位分开标识，避免把“油服”误写成与“三桶油”同一级概念。 |
| 自然资源、地调、地勘与矿业 | 自然资源主管部门、地质局/地质院、地勘集团、矿业和资源环境单位。 |
| 高校、科研院所和博士后平台 | 教师、博士后、科研助理、实验技术岗，以及不限专业或明确适配地学的行政/学生工作岗位。 |
| 事业单位、公务员和公共岗位 | 事业编、公务员、选调、人才引进及明确允许相关专业或不限专业的岗位。 |
| 金融与综合机会 | 银行、央国企和其他行业中明确允许目标专业、相近专业或不限专业的正式岗位。 |

## 4. 岗位匹配术语

| 页面术语 | 含义 | 是否可作为报名资格结论 |
| --- | --- | --- |
| 明确专业匹配 | 官方岗位正文或职位表同时给出了目标专业和可对应学历证据。 | 否。学生仍须以原公告和报名系统为准。 |
| 拓展关注/需核验原公告 | 官方岗位真实，但专业相近、学历条件不完整，或岗位明确“不限专业”。 | 否。必须清楚提示学生核验。 |
| 不匹配 | 公告明确排除该学历，或没有足以支持推荐的专业证据。 | 不在该画像筛选结果中推荐。 |

标题、单位名称、职责介绍或模型推断中出现“地质”“geology”“油气”等字样，不能单独构成“明确专业匹配”证据。

## 5. 公开与私有边界

公开学生端只展示已经通过正式原文核验的岗位。以下信息只能进入私有候选线索池，不能直接展示或进入日报：

- 中公、华图、应届生、行业招聘网站和其他聚合平台转载；
- 微信公众号文章、招聘海报、社交媒体帖子和群消息；
- 无法确认招聘主体、发布时间、有效状态或官方原文的网页；
- 需要登录、验证码、授权 Cookie 或绕过访问限制才能访问的内容。

私有线索的唯一目标是找到可公开核验的原始官方页面。找不到正式原文的线索可以保留为内部发现记录，但不得以“可能岗位”形式展示给学生。

## 6. 当前技术边界

当前系统采用 Flask 公开站点、独立 worker 和单机 SQLite 数据库。SQLite 保存结构化元数据、来源健康、扫描运行、日报快照和私有线索；原始职位表文件与证据定位将在 Phase 2 引入受控文件存储后补齐。

本项目不复制或嵌入 AGPL-3.0 的 Firecrawl、JustHireMe 实现，不部署高成本浏览器集群，也不采用代理轮换、验证码处理、浏览器/TLS 指纹伪装等方式规避官方站点访问规则。

## 7. 长期成功定义

项目成功不以单日岗位数作为唯一依据，而以以下结果衡量：

- 学生能快速找到适合学历、专业、地区和就业路径的真实机会。
- 每条公开岗位都能被解释、核验和追溯。
- 管理员能识别全国、省份、单位体系和岗位类别的覆盖盲区。
- 来源改版、停用或故障时，系统能如实报告问题并保持可维护。
- 每次功能改动都有测试、数据样例、变更说明和可回退 Git 标签。
