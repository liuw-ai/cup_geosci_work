# Phase 0 交付说明

## 交付身份

| 项目 | 值 |
| --- | --- |
| 工作分支 | `phase/0-governance-baseline` |
| 起始基线 | `1d28b3f`，`v0.3.0` |

## 本阶段变更

- 新增 `docs/phase-0/` 审阅包：项目契约、来源准入规范、验收指标、2026-09-20 基线、审阅清单和本交付说明。
- 在 `README.md`、`ARCHITECTURE.md` 中增加进入审阅包的链接。
- 新增 `pytest.ini`，将默认 pytest 收集范围限定为本站 `tests/`，避免根目录下未跟踪的参考工具项目影响本项目回归结果。

## 数据库与运行时影响

| 项目 | 结果 |
| --- | --- |
| SQLite schema migration | 无。 |
| 岗位、来源、日报、覆盖快照写入 | 无。 |
| 爬虫、worker、邮件或 Web 服务启动 | 无。 |
| 外部网站访问 | 无。 |
| 运行库读取 | 仅使用 SQLite 只读模式生成基线统计。 |

## 测试结果

```text
python -m pytest -q tests
73 passed in 1.97s
```

首次执行未限定路径的 `python -m pytest -q` 时，pytest 递归发现了未跟踪 `参考工具/` 中 curl_cffi 的测试，并因该参考项目缺少本项目未声明的 `litestar` 依赖而在收集阶段停止。这不属于本站测试失败。新增 `pytest.ini` 后，默认命令将只收集本站 `tests/`；提交前必须再次执行默认命令确认该隔离生效。

```text
python -m pytest -q
73 passed in 1.13s
```

## 审阅前的已知限制

- Phase 0 文档定义的是后续实现必须满足的契约；PDF/Excel 行级解析、单位矩阵、公众号发现流、全文检索、性能缓存和部署恢复演练尚未在此阶段实施。
- 2026-09-20 基线报告是运行库快照，不是对全国招聘市场的实时声明。
- `v0.4.0` 只在用户审阅通过、工作分支合并到 `master` 后创建；在此之前，现有 `v0.1.0`、`v0.2.0`、`v0.3.0` 保持不变。
