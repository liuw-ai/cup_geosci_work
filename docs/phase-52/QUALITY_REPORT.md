## 回归门禁

- 每条记录必须同时有专业、学历、地点、招聘人数、报名截止和官方详情链接。
- 每条记录的 `official_evidence_url` 必须指向总局官方公告。
- 每条 `student_eligible` 记录的专业范围必须包含目标专业证据。
- 详情访问失败不能转化为“无岗位”。

## 接入现有数据库后的同步复核

本地执行一次完整 `sync` 后，数据库审计结果为 1033 条历史岗位、223 条开放岗位。该次同步新增 28 条、更新 22 条、清退 0 条；国聘来源本次发现 33 条、开放匹配 21 条，新增 23 条、更新 10 条。

同一轮同步还记录了真实来源状态：

- 中国石化浏览器快照因超过 30 小时未更新而标记 `failed`，没有生成新岗位。
- 中国石油浏览器捕获文件缺失，标记 `failed`，没有生成新岗位。
- 27 个来源因 robots、TLS EOF 或 HTTP 403/502 无法完成合规预检，标记为 `blocked`/`degraded`。
- 这些状态均未被计入“扫描成功无匹配”，也未从学生端删除已有仍在有效期内的岗位。

来源集中度质量门禁仍为 `needs_attention`：当前开放岗位中中国石化历史快照占比约 64.6%。这说明本阶段虽然修复了国聘分页和字段完整性，但没有完成全国国内来源分散化目标，下一阶段必须优先补齐三桶油下属单位和省级事业编/公务员来源。

## 结论

本阶段证明国聘动态系统中的国内地勘岗位可以被完整分页发现并提取岗位级字段，但尚未完成服务器端浏览器 worker 的每日自动化。全国三桶油、事业编和公务员的总体扩容目标仍未完成。
