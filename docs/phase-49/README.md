# Phase 49：省级事业单位当前扫描与过期证据回归

本阶段继续面向中国石油大学（北京）地球科学学院学生，重点验证“当前无岗位”和“来源故障”必须分开。服务器直连扫描了湖南省地质院正式通知栏目，发现两类容易误发布的公告：

- 湖南省 2026 年省直事业单位第四次公开招聘：公告和官方 XLSX 岗位表可访问，报名时间为 2026-09-09 至 2026-09-16。岗位表 160 行、255 个计划，其中 14 行（15 个计划）明确包含地质学、地质工程、地质资源与地质工程、资源勘查工程或地球物理等目标专业，但截至 2026-09-27 已结束，只进入 `verified_closed` 历史回归批次。
- 湖南省地质调查所 2026 年公开选拔：公告明确“面向湖南省地质院系统符合条件的正式在编人员”，报名时间为 2026-09-04 至 2026-09-10，不面向社会毕业生，不进入学生端。

本阶段没有把已截止岗位或内部人员选拔伪装成在招岗位，也没有新增公务员记录。省级公务员当年度正式职位表仍未找到可核验的当前开放版本，国家公务员入口继续保持 `source_unavailable`，不导入历史表。

## 新增契约

政府来源评估新增 `verified_scan_no_current_match`：表示官方入口、公告和附件均已成功扫描，但当前没有可发布的专业匹配岗位。它与 `source_unavailable`、`manual_review_required` 分开统计。
