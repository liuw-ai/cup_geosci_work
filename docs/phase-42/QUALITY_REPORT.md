## 解释

服务器上本轮实际扫描了中国煤炭地质总局、中国冶金地质总局下属单位、中国地质
调查局、北京人社、中石油东方地球物理、中海油服等官方入口。扫描成功但没有当前
专业匹配的来源继续标记为 `scan_success_no_match`；访问受限或连接失败的来源仍
标记为故障，不会被写成“没有招聘”。因此岗位数没有人为增长，符合真实性门禁。

当前质量门槛仍未通过来源集中度检查：中石化占公开岗位约 71.64%，事业编/公务员
类别仍需要最新官方职位表。这个缺口是真实的扩源工作，不通过增加历史或泛专业岗位
来掩盖。
