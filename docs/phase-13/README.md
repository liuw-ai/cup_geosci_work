# Phase 13：岗位级专业证据与日期一致性

本阶段先修复“标签与原公告不一致”的高风险问题，再继续扩大来源规模。

## 已完成

- 中国石油大学（北京）就业网的结构化职位表按行拆分，一行岗位对应一条 `RawPosting`。
- 专业、学历、地点和岗位名称保留在 `field_evidence`，并写入岗位数据库。
- 多岗位公告不再把整篇公告的专业简介复制到每一条岗位。
- 没有岗位级专业证据的画像匹配只能标记为“需核验原公告”，不能标记“明确匹配”。
- 移除“地质资源”作为“地质资源与地质工程”的明确匹配别名。
- 主页日报预览使用站点时区日期，避免跨日后继续显示旧日期。
- 岗位详情页展示岗位级专业/学历/地点原文和表格行位置。
- 常驻 worker 会自动处理已经登记的官方附件；解析结果仍停留在管理员复核队列。

## 本阶段边界

本阶段没有伪造或批量补录招聘信息，也没有绕过目标站点的 robots、验证码或访问策略。现有历史岗位不会自动被重新判定为真实岗位；下一阶段需要在备份数据库后，对 CUPB 历史记录重新采集、复核或降级为待核验。
