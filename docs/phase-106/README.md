# Phase 106: CNPC detail navigation and production checkpoint

## Purpose

中国石油官方 `recruitInfoshow.html` 页面在只带岗位 `id` 时可能渲染为空壳；
岗位快照已经有官方岗位标题和编号，但学生点击后仍看不到详情。本阶段只修复
官方详情路由的导航参数，不补写或推断岗位字段。

## Change

- 新采集的 CNPC 快照详情 URL 自动保留原有查询参数并补充 `postName`。
- 旧数据库记录在读取展示时同样补充 `postName`，因此不必等待下一次成功采集才修复学生端链接。
- `field_evidence["官方详情链接"]` 与展示 URL 同步，便于审计。
- 不改变专业、学历、地点、人数、截止日期、来源状态或发布门禁。

## Honest completion assessment

本阶段解决了一个学生点击即失效的真实性/可用性缺陷，但没有增加新的官方岗位来源，
因此总完成度不因测试数量上升而虚增，仍约为 **72/100**。全院正式版的主要缺口仍是：

1. 31 省 155 个官方角色目标中只有 19 个已核验，38 个候选、98 个尚未定位。
2. 公务员当年度官方职位表仍未确认，学生端保持零历史冒充在招岗位。
3. 三桶油下属单位来源不均衡，CNOOC 已有浏览器链路，CNPC、Sinopec、PipeChina 仍受官方访问/维护策略影响。
4. 事业编岗位来源集中在少数地质系统，必须增加不同省份的当前官方岗位表并完成每日复核。
5. DNS/域名仍按用户决定暂缓，不计入本阶段功能完成度。

## Next acceptance gate

下一阶段必须产生新的、可重复更新的官方岗位来源，才允许提升评分：

- 至少新增 2 个省份的当前事业编官方职位表，逐岗位保留公告、附件、专业、学历、地点、人数和截止日期；
- 至少新增 1 个三桶油下属单位的岗位级官方详情采集或可复核公告链路；
- 每个新增来源连续两次成功刷新，过期岗位能自动清退；
- 公开岗位来源不得由单一来源贡献超过 70%；
- 公务员职位表只有在当年度官方发布并完成附件核验后才导入。

未满足以上条件前，不宣称达到 75 分或全院正式版。
