## 真实性与安全边界

- 组织名称、官方域名和入口只从现有可审查单位别名表、既有来源白名单及用户提供的官方渠道中整理；本阶段不使用第三方聚合页填充公开数据。
- JSON 中的 URL 需要通过契约格式校验，但“官方确认”不是机器人可访问性承诺。是否允许自动化仍由 `sources.json`、robots 检查、来源健康与抓取运行记录共同决定。
- 对动态、登录、验证码、TLS 异常或年度页面变化的入口，状态保持 `official_confirmed` 或更低，不会以 `automation_ready` 伪装。
- `backup_rate` 只衡量是否登记备用官方入口；真正可用的 fallback 要在后续逐站健康检查与回归中单独证明。
- 公开 `/api/coverage` 不返回频道 URL、备用链接、来源绑定、核验备注或候选状态；完整明细由管理员令牌保护。

## 未完成项

- 三桶油各油田、区域公司、研究院、工程技术单位尚未扩展到“上千家单位”的完整矩阵；当前是高价值、可维护的种子台账。
- 31 省的五类来源仍须逐省定位、确认当前栏目、样例公告、职位表附件、robots 和解析规则。不能把现有 31 省目标表视为完成采集。
- 本阶段未新增岗位，也没有用组织入口触发抓取；岗位数量和明确匹配覆盖指标需要在后续合规扩源后再提升。
- 正式招聘系统的自动化成功率不能预先承诺。每个站点都要单独验证公开访问方式和回归测试。
