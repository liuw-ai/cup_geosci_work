# Phase 3 交付说明

## 变更摘要

- 新增 `data/organization_registry.json`，提供集团到下属单位的层级、产业角色、正式校招/社招/公告/科研招聘频道、备用官方入口与来源绑定。
- 新增 `job_hub/organizations.py`，将组织入口配置与岗位单位别名表分离，提供验证、聚合、角色筛选和管理员展示行。
- 扩展 `job_hub/contracts.py`，对组织 ID、父子层级、角色、频道类型、URL、来源绑定、状态和唯一主频道进行约束。
- 扩展 `job_hub/coverage.py`，在公开覆盖报告中提供组织矩阵的聚合指标，不泄露频道明细。
- 扩展 `job_hub/app.py`，新增受 `X-Admin-Token` 保护的 `GET /api/admin/organization-matrix`。
- 扩展 `job_hub/cli.py`，新增只读 `organization-matrix` 运维命令。
- 补充中油测井有限公司的可靠名称变体，便于公告单位名标准化。
- 不新增岗位、不修改 SQLite 模式、不改变学生端页面布局。

## 审阅重点

1. 组织角色是否符合地球科学学院学生阅读习惯，尤其是不要把油田运营主体、集团内油服、独立油服和国际油服混为一类。
2. 招聘入口是否严格标注状态，不把“官方首页”或“已登记招聘平台”误读为正在稳定抓取。
3. 管理员接口是否提供足够的排期信息，同时没有把内部核验备注暴露给学生端。
4. 该模型是否足以支撑下一阶段按单位矩阵和 31 省五类官方来源分批扩源。
