# Phase 48: Government Open-Ended Recruitment Expansion

本阶段扩展事业单位官方职位表，并修正“招满即止”岗位的生命周期契约。

## 新增官方岗位

- 湖北省空间规划研究院：矿产资源管理岗 1 人。来源为湖北省自然资源厅官方公告和 XLSX 岗位表；专业明确包含地质学、地质资源与地质工程，学历为全日制硕士研究生及以上。公告说明“自公告发布之日起，招满即止”，且为劳务派遣用工，学生端不得宣传为正式事业编。
- 甘肃省地质矿产勘查开发局第三地质矿产勘查院：地质勘查以及测绘遥感科研岗 3 人。来源为甘肃省地矿局官方调整版岗位表，博士研究生，明确包含地质学、地质资源与地质工程。
- 甘肃省地质调查院：地质勘查科研岗 2 人。来源为甘肃省地矿局官方调整版岗位表，博士研究生，明确包含地质学、地质资源与地质工程。

政府职位台账由 6 条增至 9 条，全部为 `explicit_match`。湖南 2026 年第四次招聘等已截止公告仍不发布；国家公务员 2027 职位表尚未确认发布，也不导入历史职位。

## 生命周期规则

`deadline_policy` 现在只有两种值：

- `fixed_date`：必须有 `deadline_date`，到期由现有清退逻辑下线。
- `open_until_filled`：官方明确“招满即止”但没有固定截止日，`deadline_date` 保持为空；岗位会发布，但要求每日复核来源状态，不能伪造截止日期。

该字段同时写入职位台账和官方附件台账，避免附件队列把长期开放岗位误标为过期。

## 证据范围

学生端只使用政府官网公告、政府官网 PDF/XLS/XLSX 附件和附件行定位。中公、华图、公众号和搜索摘要不作为学生端证据。
