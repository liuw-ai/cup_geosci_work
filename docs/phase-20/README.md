# Phase 20：中国石油详情页异常透明化

本阶段处理学生反馈的“点击官方岗位后页面空白”问题，不把空白页面误认为完整公告，也不删除已核验的岗位数据。

## 核实结论

中国石油详情页由 `recruitInfoshow.js` 调用 `POST /web/recruitInfo/showN?recruitId=<opaque-id>`。2026-09-24 在浏览器逐个复核时，接口回调缺少 `recruitInfoObj`，前端因此在读取 `recruitTitle` 时抛出异常；资格要求、招聘岗位和企业介绍区域全部保持空白。截图中的 `27012269` 是岗位业务编号，URL 中的 `8b8b...` 是官网详情记录的内部 `recruitId`。

## 处理方式

- 保留管理员从中国石油官方招聘系统核验的岗位快照和字段证据。
- 在学生端明确显示“官方详情接口当前异常”，展示内部详情编号。
- 主按钮改为中国石油官方招聘列表入口，学生可在官网内重新核对岗位编号、资格条件和报名状态。
- 保留原详情页作为“尝试打开岗位详情页”链接，不再将其标注为当前可用的完整原文。
- 采集器和人工导入都统一补充详情编号、官方入口和接口状态，避免路径不同导致信息缺失。

## 当前地学岗位覆盖检查

当前公开在招岗位共 123 条。按中国石油大学（北京）地球科学学院培养方向检查，每个方向均有明确专业与学历匹配：本科资源勘查工程 33 条，硕士地质学 67 条、地质工程 84 条、地质资源与地质工程 86 条，博士地质学 25 条、地质工程 24 条、地质资源与地质工程 29 条。该检查不使用 100 人模拟数据。

## 后续扩容

继续扩展中国石油下属油田、研究院和工程技术单位时，必须优先寻找可直接打开的官方公告、职位表附件或公开 API；详情接口异常的来源只能进入快照/人工复核链路，不能用空白页宣称实时可采集。
