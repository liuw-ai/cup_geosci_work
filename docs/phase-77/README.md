# Phase 77 全院正式版推进：详情采集稳定性与政府附件扩展

本阶段的目标是把全院正式版的每日采集链路继续向可发布状态推进：

- 保持岗位级专业、学历、地点和官方证据门禁不变；
- 修复 SLB 官方详情页采集因时间预算过紧而被误判为来源失败的问题；
- 在服务器上复核阶段 76 的中石化完整快照、事业编附件队列和每日 Worker；
- 不把访问受限、解析失败、扫描成功无匹配和报名截止混为“无岗位”。

阶段 77 不宣称已经完成全国 31 省和当年度公务员职位表。公务员职位表仍必须等待当年度官方公告及职位表附件，并逐行核验后才能发布。

## 本阶段变更

`data/sources.json` 将 SLB 详情页时间预算从 50 秒调整为 120 秒，覆盖最多 12 个候选详情页（单页请求超时 8 秒）。新增回归测试保证生产配置预算不低于候选详情上限乘以请求超时。

## 验收门槛

1. 本地测试、编译、Compose 配置和差异检查全部通过。
2. 服务器审计通过，且 Worker 心跳不超过 5 分钟。
3. 中石化 132/35/363 捕获快照通过完整性和分页门禁。
4. SLB 若仍失败，必须记录具体官方访问或详情解析原因，不得发布半截结果。
5. 政府附件仍按官方公告、附件哈希、逐行证据和报名窗口门禁处理。
