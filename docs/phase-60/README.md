# Phase 60: 公网访问与官方岗位复扫

本阶段解决两件事：在正式域名 DNS 尚未生效时保持可验证的公网访问；复扫已登记的政府、地调和地勘官方入口，寻找可满足学生端发布门禁的当前岗位。

## 公网状态

- 临时访问地址：`http://81.70.62.174/`。这是仅用于核验的 HTTP 地址，不能作为正式宣传链接。
- 正式地址：`https://jobs.cupdky.cn/`。当前仍不可用，因为 `cupdky.cn` 根域没有公共 DNS 委托，`jobs.cupdky.cn` 返回 `NXDOMAIN`。
- 反向代理、80/443 端口和 Caddy 自动 HTTPS 已在服务器就绪。DNS 生效后 Caddy 会自动申请并续期证书。

域名所有者必须在注册商或 DNS 服务商完成：确认 `cupdky.cn` 已注册并启用 DNS 托管，然后添加 `A` 记录 `jobs -> 81.70.62.174`，TTL 设为 `600` 或 `Auto`。根域没有 DNS 托管时，只添加子域记录不会生效。

## 复扫范围

本轮服务器直连复扫了山东人事考试、山东省地矿局、河南省地质局、天津市规划和自然资源局、河北省地矿局，以及中国地质调查局、自然资源部、中国煤炭地质总局、中国冶金地质总局和中国科学院等已注册官方入口。

结果：本轮没有发现同时满足“当前有效、岗位级专业或不限专业、学历、地点、人数、有效期和官方原文证据”条件的新记录。因此学生端没有新增政府岗位。公告过期、字段不足、非目标专业和访问故障均没有被包装成岗位增长。

## 下一门禁

只有在下列任一条件成立后，才可宣称政府岗位覆盖有实质增长：

1. 找到仍在报名期的官方职位表，并逐行验证字段；
2. 中国地震局 2027 招聘在 `2026-10-10` 开放后，来源复核成功并自动发布其 70 条已核验岗位；
3. 当年度国家或省级公务员官方职位表发布并完成附件解析。

正式域名验收：

```bash
docker compose exec -T web python -m job_hub.cli domain-check \
  --hostname jobs.cupdky.cn --expected-ip 81.70.62.174
```
