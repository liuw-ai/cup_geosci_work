# Phase 32：中国石油单位矩阵与岗位证据绑定

本阶段把中国石油的“单位入口”和“岗位数据”拆开审计。单位矩阵来自已登记的官方来源扩展队列，岗位来自 2026-09-24 经管理员核验的中国石油官方岗位快照。

## 交付内容

- 13 个中国石油单位进入矩阵：集团研究院、10 个油田/油气田、东方物探和中国石油集团测井有限公司。
- 每个单位都有官方入口、备用官方入口、组织角色、当前证据状态和下一步动作。
- 20 条快照岗位逐条绑定到 10 个具体油田单位；每条保留官方证据 URL、岗位编号、专业、学历、地点和招聘人数证据。
- 新增管理员只读接口 `/api/admin/cnpc-matrix` 和 CLI `cnpc-matrix`。
- 不把只有单位主页、访问受限或尚未取得岗位级证据的单位显示为学生端岗位。

## 运行方式

```bash
python -m job_hub.cli cnpc-matrix \
  --snapshot data/verified/cnpc-geoscience-20260924.json
```

该命令只读审计，不会新增或修改岗位。后续浏览器捕获、官方附件导入和人工复核都必须先通过同一审计契约。
