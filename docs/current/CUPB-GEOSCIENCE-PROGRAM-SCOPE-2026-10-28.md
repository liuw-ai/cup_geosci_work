# 地球科学学院专业范围核验（2026-10-28）

## 核验结论

项目当前“4 个毕业专业、8 个学历 x 专业画像”的运行定义是：

| 学历层次 | 当前画像专业 | 项目用途 |
| --- | --- | --- |
| 本科 | 资源勘查工程 | 企业岗位精确匹配与公共岗位代码匹配 |
| 本科 | 地质学 | 企业岗位精确匹配与公共岗位代码匹配 |
| 硕士、博士 | 地质学 | 企业岗位精确匹配与公共岗位代码匹配 |
| 硕士、博士 | 地质工程 | 企业岗位精确匹配与公共岗位代码匹配 |
| 硕士、博士 | 地质资源与地质工程 | 企业岗位精确匹配与公共岗位代码匹配 |

这不是学院所有教学、科研方向或全部培养专业的完整名单。学院官网当前明确列有两个本科专业：地质学、资源勘查工程；并列有地质学、地质资源与地质工程两个一级博士/硕士学位授权点，以及地质工程博士/硕士专业学位授权点。项目负责人于 2026-10-28 明确要求学院对应专业纳入，因此“本科地质学”已纳入运行画像；这不扩大四个毕业专业名称，也不把相邻方向或石油工程升级为精确匹配。

## 官方依据

- [学院简介](https://www.cup.edu.cn/geosci/xygk/xyjj/index.htm)：说明学院现有国家级一流本科专业资源勘查工程、北京市一流本科专业地质学；并列出地质学、地质资源与地质工程一级博士/硕士点和地质工程专业学位点。
- [本科专业设置](https://www.cup.edu.cn/geosci/xkjs/bkzysz/index.htm)：列出资源勘查工程（油气与清洁地质能源）及中俄复合人才实验班。
- [学科设置](https://www.cup.edu.cn/geosci/xkjs/bssqxk/index.htm)：地质资源与地质工程方向包括盆地分析与资源评价、油气及伴生资源成藏成矿与勘查、地下资源开发地质、非常规能源地质工程一体化、能源资源大数据与智能工程、储量评估与管理；地质学方向包括沉积学与古地理、岩石学与储层地质、有机地球化学及化石能源、大地构造与油区构造等。
- [主要研究方向](https://www.cup.edu.cn/geosci/kxyj/yjfx/index.htm)：学院重点包含复杂地质条件下油气成藏与探测、复杂油气藏开发地质与剩余油预测、沉积盆地动力学、油气成因与油藏地球化学、非常规油气资源、油气藏地质等。
- [能源地质工程系](https://www.cup.edu.cn/geosci/jgsz/nydzgcx/index.htm)：2026 年成立，开展油气及清洁伴生地质能源、CCUS、储能的地质工程一体化研究，并承担上述三类地学硕博培养；它不是新增的独立学生画像名称。

## “油气开发”与“石油工程”边界

“油气开发地质”在学院的语境中是地质学/地质工程问题，例如油气藏地质评价、储层表征、剩余油预测、成藏与开发地质一体化。它不等同于石油工程学院的油气田开发工程，也不等同于钻井、完井、压裂、采油工艺等纯石油工程岗位。

因此当前门禁应保持以下规则：

1. 岗位仅列“石油工程、油气井工程、油气田开发工程”等，且没有当前画像专业或公共招录大类/代码依据时，仍为不匹配。
2. 岗位同时列“地质工程、地质学、地质资源与地质工程、资源勘查工程”之一，或公共职位表用已核验代码覆盖时，可以公开；其余石油工程方向只作为辅助发现线索。
3. “油气开发地质、储层地质、石油地质、物探、测井”等相邻措辞本身不能自动等同于四个画像专业，但可以在页面中显示为宽泛地学匹配或待核验，前提是岗位级官方证据成立。

这一区分避免错过学院学生可能胜任的开发地质机会，也避免把纯钻完井/采油工艺岗位错误承诺给学生。
