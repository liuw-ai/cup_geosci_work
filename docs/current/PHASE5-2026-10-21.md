# Phase 5 任务边界

Phase 5 从 Phase 4 冻结状态开始。它是后续开发计划，不表示任务已经完成，也不授权自动化或服务器发布。

## 必须完成的工作

1. 扩大真实第三方职位表批次。优先中公、粉笔、华图，其次公考雷达和公考资讯网；每批必须保存汇总页、职位表 URL、访问时间、文件类型、大小、SHA-256、批次号和逐行定位。
2. 对每个职位表行回溯官方公告、官方岗位表、官方详情页或官方报名入口；没有官方岗位级证据的行只能停留在私有候选，不得进入学生端。
3. 将第三方职位表解析、官方回溯、人工核验和正式入库扩展到可审计规模。500 条是最低目标，不把现有 678 条学生端岗位冒充第三方完成量。
4. 对中国石油、中国石化、中国海油的 239 个展示候选逐个补充法定名称、组织关系和外部身份来源；未完成核验的继续保持候选状态。
5. 逐项补齐三桶油单位招聘入口证据，明确区分单位独立入口、集团共享平台展示、官方主页和来源暂时不可用。
6. 建立管理员审核工作台或等价的可审计审核界面，减少仅依赖命令行和 API 的人工操作。
7. 保持本地临时数据库测试、Manifest 哈希绑定、回滚备份和阶段文档一致性；每个批次先在隔离库验证，再决定是否合并本地正式库。

## 发布门禁

- 未经用户再次明确批准，不部署 Phase 5 到服务器。
- 未通过完整测试、Manifest 校验、数据库完整性和学生端验收，不进入发布候选。
- 不绕过 robots、验证码、登录、TLS、403、412 或浏览器权限限制。
- 不以第三方转载页作为学生申请链接，不以公告总人数伪造岗位行。
- 来源暂时不可用不能撤回曾经有官方成功证据的岗位。

## 品牌边界

- 2026-10-21 已确认的公共页头校徽属于 Phase 4 发布候选，不再作为 Phase 5 试用内容。
- `job_hub/static/brand-mark.svg` 保留为浏览器标签图标；未经单独确认，Phase 5 不改变已确认的公共页头、站点名称、学院归属、导航或页脚。

## 学生端来源状态展示（2026-10-22）

- `source_unavailable`、`degraded`、`stale_pending_review` 继续作为数据库和内部审计状态，不改变岗位生命周期或官方证据保存规则。
- 学生端岗位卡片、详情页、筛选项和公开 API 不展示来源健康状态、失败原因、内部接口状态或对应层级标签。
- 对仍保留的岗位，详情页只提示“岗位是否仍可申请，请以保留的官方链接和最新公告为准”，并继续提供官方原文、官方报名入口和官方岗位表链接（存在时）。
- 此项只改变展示与公开 API 脱敏边界；不启动 Worker，不触发采集，不修改生产数据库业务字段。
