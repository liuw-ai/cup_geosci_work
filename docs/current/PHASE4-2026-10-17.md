# Phase 4 本地实施记录与边界

日期：2026-10-17（Asia/Shanghai）

本文件记录 Phase 4 的本地实施边界。它不是服务器发布批准，也不把外部官网尚未核验的单位或岗位写成正式事实。

Manifest 采用两步提交：第一步提交代码、配置和验收事实；第二步提交只包含 Manifest 的元数据更新。Manifest 中的 `git_sha` 指向第一步的可复现输入提交，`working_tree_dirty=false` 表示该输入提交没有未提交改动，不把 Manifest 自身的写入过程误判为脏工作树。

## 目标

1. 保持 Phase 3 的生命周期与学生端规则。
2. 将第三方职位表真正接入“证据留存 → 私有候选 → 官方回溯 → 人工核验 → 正式岗位”的可审计漏斗。
3. 扩充三桶油组织候选，但只有官方证据才能进入正式三桶油目录。
4. 修正当前文档与数据库统计不一致的问题。
5. 只在本地隔离数据库测试；未经用户明确批准不部署服务器。

- 候选线索现在显式保存 `discovery_source_id`，因此可以按渠道统计“表格行 → 候选 → 官方回溯 → 核验 → 发布”的漏斗。
- 候选正式发布动作现在还会复核关联岗位的学生端发布层级；官方内容已核验但岗位仍未通过专业/学历/地点门禁时，不能被错误标记为 `published`。
- 新增湖南有色金属研究院官方手工核验源登记；第三方发现链接只保留为内部证据，正式岗位详情使用企业官网公告。

## 第三方正式岗位定义

“官方申请链接”是学生点击后能够进入官方报名、投递或招聘系统中对应岗位/批次的 HTTP(S) 地址，例如官方招聘系统的岗位详情页、官方报名页面或官方公告明确指定的报名入口。它不是中公、粉笔、华图的转载页，也不是第三方职位表的下载地址。

第三方职位表链接只作为内部证据。只有当该表本身由政府或用人单位官方发布时，才可在学生端以“岗位表链接”显示；第三方表格仍然不能作为申请链接。

每个第三方行必须保存：第三方汇总页、第三方表格地址、下载时间、内容类型、大小、SHA-256、批次、工作表/行定位、官方公告或表格地址、官方详情/报名地址、人工核验人和核验时间。

## 本轮关键路径复核

- `db.withdraw_missing_source_jobs()`、`db.withdraw_stale_source_jobs()` 和 `pipeline.expire_stale_source_jobs()` 当前均为兼容性 no-op；扫描缺失、来源停用和 30 小时新鲜度不会改变岗位状态。
- `db.save_job()` 与附件岗位撤回路径只接受 `major_mismatch`、`deadline_passed`、`official_cancelled`、`official_closed`、`official_replaced`，且附件撤回还要求 HTTP(S) 官方证据地址。
- 学生端 CTE 明确排除 `superseded`，并只按截止日期或无截止日期 90 天规则过滤；`_source_capture_freshness_filter()` 返回中性条件，不参与公开门禁。
- B 级第三方网络表格下载在 `_robots_permit()` 通过前不会发起附件请求；robots 拒绝或无法核验只产生访问受限异常。离线人工提供的真实文件不会冒充网络抓取或官方证据。
- 模板只展示 `official_link_url`、`application_url` 和官方 `official_table_url`；第三方汇总页和第三方表格地址留在管理员证据/线索记录中，不作为学生申请链接。
