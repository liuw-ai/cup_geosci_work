# Phase 4 本地实施记录与边界

日期：2026-10-17（Asia/Shanghai）

本文件记录 Phase 4 的本地实施边界。它不是服务器发布批准，也不把外部官网尚未核验的单位或岗位写成正式事实。

## 目标

1. 保持 Phase 3 的生命周期与学生端规则。
2. 将第三方职位表真正接入“证据留存 → 私有候选 → 官方回溯 → 人工核验 → 正式岗位”的可审计漏斗。
3. 扩充三桶油组织候选，但只有官方证据才能进入正式三桶油目录。
4. 修正当前文档与数据库统计不一致的问题。
5. 只在本地隔离数据库测试；未经用户明确批准不部署服务器。

## 本轮补强（本地）

- 候选线索的 `official_application_url` 已成为可独立编辑、校验和发布的数据库字段；正式岗位发布优先使用该字段，只有缺失时才回退到历史 metadata。

## 第三方正式岗位定义

“官方申请链接”是学生点击后能够进入官方报名、投递或招聘系统中对应岗位/批次的 HTTP(S) 地址，例如官方招聘系统的岗位详情页、官方报名页面或官方公告明确指定的报名入口。它不是中公、粉笔、华图的转载页，也不是第三方职位表的下载地址。

第三方职位表链接只作为内部证据。只有当该表本身由政府或用人单位官方发布时，才可在学生端以“岗位表链接”显示；第三方表格仍然不能作为申请链接。

每个第三方行必须保存：第三方汇总页、第三方表格地址、下载时间、内容类型、大小、SHA-256、批次、工作表/行定位、官方公告或表格地址、官方详情/报名地址、人工核验人和核验时间。

## 组织目录边界

`data/three_oil_organization_catalog.json` 是正式三桶油目录；`organization_registry.json` 是更大的登记和入口账本。截图简称、招聘展示名和 `*-display-*` 记录只能进入 Phase 4 对账报告，不能自动升格为法定单位。

全量对账见 [phase4-organization-reconciliation-2026-10-17.json](phase4-organization-reconciliation-2026-10-17.json)。该报告逐条列出三桶油关键词相关组织、旧角色、频道状态和待补证据，不改变正式目录。
