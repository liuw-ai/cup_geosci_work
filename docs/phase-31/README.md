# Phase 31：中国石化候选单位官方详情采集

本阶段使用公开浏览器页面读取中国石化校园招聘 SPA 的官方渲染结果，建立 132 个单位清单，并逐一核验关键词筛出的 35 个候选单位详情页。浏览器捕获先保存为版本化 JSON，再经过单位绑定、分页完整性、字段完整性和学生端专业门禁后进入服务器。

## 采集结果

- 官方平台：`https://job.sinopec.com/`
- 单位清单：132 个；其中 35 个为“地质”关键词候选单位。
- 候选单位详情：35/35 成功。
- 候选岗位分页：35/35 完成。
- 岗位行：397 条，失败行 0 条。
- 每条岗位保留单位详情页 URL、岗位、专业、学历、地点、招聘人数和截止时间证据。
- 学生端发布门禁后，本次同步产生 75 条明确匹配岗位；其余岗位保留在管理员审计库中，不向学生端展示。

## 访问边界

服务器普通 HTTP 请求可以打开首页，但 `robots.txt` 返回 HTTP 403，岗位接口在无浏览器会话时返回业务错误。此次捕获使用公开浏览器中可见的页面内容，不登录、不提交申请、不调用私有接口、不绕过验证码或访问控制。当前快照是经审计的官方证据版本，尚未宣称服务器已经无人值守地实时浏览器采集。

## 证据与门禁

岗位行的证据 URL 是对应官方单位详情路由，例如：

```text
https://job.sinopec.com/#/school/recruitEnterpriseDetail?deptId=...
```

详情页中显示的截止时间原文保留在 `field_evidence`，标准 `deadline_date` 归一化为 ISO 日期。单位扫描失败、分页不完整或字段缺失均不能进入学生端。
