# Phase 36：事业编岗位核验与公务员年度门禁

日期：2026-09-26  
分支：`phase/36-government-publication-gate`

## 本阶段目标

在中国石油 00:00–06:00 维护窗口之外，先完成政府招聘链路中可以被官方原文证实的部分：

- 服务器已受控下载安徽省地质矿产勘查局官网公告附件；
- 从官方岗位表中定位两条明确匹配地球科学学院博士专业的岗位；
- 使用公告正文的单位地址补齐地点证据，保留公告页、附件 URL、哈希和表格行号；
- 事业编岗位只有完成地点与专业/学历核验后才允许进入学生端；
- 公务员年度职位表尚未取得当年官方附件时，继续显示为来源待核验，不使用历史职位表充数；
- 页面页脚增加可配置的项目归属署名和数据责任说明。

## 公务员边界

国家公务员局入口已登记，但本年度正式职位表尚未取得可验证的官方公告/附件。系统不会把历史职位表、聚合站或搜索结果标记为当前在招。职位表发布后必须逐行核验职位代码、机关单位、地点、学历、专业、招录人数、报名截止日期和官方附件证据。
