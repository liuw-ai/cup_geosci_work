# Phase 38：中海油服官方北森岗位适配器

日期：2026-09-26  
分支：\`phase/38-cosl-official-adapter\`

## 本阶段目标

将中海油田服务股份有限公司公开招聘入口接入统一采集链路，并验证：

- 只调用招聘门户自身公开的只读岗位接口；
- 校园、社会、实习三类入口按分页读取，保存岗位编号和官方详情 URL；
- 同一份公告中重复出现的专业类别章节全部合并，避免遗漏本科专业；
- 岗位职责、专业类别、学历、地点和来源接口保留为岗位级证据；
- 学生端仍只发布明确匹配中国石油大学（北京）地球科学学院培养方向的岗位；
- “面试信息采集”、面试名单、拟录用和录用公示不作为在招岗位；
- 采集失败与扫描成功但无匹配严格区分。

## 官方来源

- 官方单位首页：\`https://www.cosl.com.cn/\`
- 官方公开招聘门户：\`https://cosl.zhiye.com/\`
- 门户公开只读接口：\`https://cosl.zhiye.com/api/Jobad/GetJobAdPageList\`
- 岗位详情模板：\`https://cosl.zhiye.com/campus/detail?jobAdId={job_id}\`

接口仅在官方招聘页面公开调用，不使用登录、投递、验证码或内部管理接口。

## 真实扫描结论

2026-09-26 服务器直连探测到校园分类返回 1 条官方广告，标题为“中海油服2026年校园招聘（面试信息采集）(J10534)”。该广告包含 50 个可解析的岗位角色块和完整的地质类专业章节，但不是当前可投递岗位，生产过滤后公开新增数为 0。社会招聘和实习分类当前返回空列表，不能解释为来源故障。

因此本阶段的交付是“官方接口和证据解析链路完成”，不是人为增加岗位数量。待官方门户发布真正的招聘公告后，下一次每日同步可自动发现；若接口失败会记录来源故障，不会显示为“无岗位”。
