# Phase 50：省级公务员官方入口扫描

本阶段继续服务中国石油大学（北京）地球科学学院本科资源勘查工程、硕士/博士地质学、地质工程、地质资源与地质工程学生。目标是把省级公务员入口从“未定位”推进到可审计扫描，而不是把已经结束的考试或面向在编人员的遴选包装成当前岗位。

## 本阶段完成

- 服务器直连核验山东省人力资源和社会保障厅公务员公告：2026 年度省级机关及直属机构网上报名为 2025-11-07 至 2025-11-10，已结束，记录为 `verified_scan_no_current_match`。
- 服务器直连核验浙江省公务员考试录用专题：页面保留 2026 年招录、专项招录和下半年面向基层遴选入口，但当前可见的下半年遴选面向在编公务员，没有面向本院社会毕业生且仍在报名的地学职位表，记录为 `verified_scan_no_current_match`。
- 两个入口均保留官方备用入口；没有创建公务员岗位行，不把已截止职位表或在编人员遴选导入学生端。
- 回归测试验证省级公务员扫描记录存在、截止门禁生效、逐岗位公务员记录仍为零。

## 当前边界

省级公务员考试通常按年度集中发布，2026 年山东招录已在 2025 年 11 月完成报名；浙江当前页面的遴选对象不是应届毕业生。因而本阶段没有真实的“仍在报名且专业明确匹配”公务员岗位可发布。这是扫描结论，不是来源故障，也不代表以后没有岗位。

后续年度职位表发布后，必须从官方职位表或官方查询系统导入职位代码、招录机关、专业代码、学历、地点、人数和报名截止日期，再通过地学专业门禁。
