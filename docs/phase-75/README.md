# Phase 75：附件岗位资格条件门禁

## 目标

项目服务对象是中国石油大学（北京）地球科学学院的在校本科生、硕士生和博士生。岗位的专业和学历即使明确匹配，只要同一官方岗位行要求多年工作经验，就不能作为面向学生的机会发布。

此前附件流水线保存了每一岗位行的原文，但发布门禁只读取已映射的专业、学历和地点字段。任职条件若位于“任职资格”“工作经验”等独立列，可能没有参与学生端判断。本阶段把该遗漏补为硬门禁。

## 实现

- 附件解析器识别“岗位要求、任职要求、任职条件、任职资格、资格条件、招聘条件、应聘条件、工作经验、工作年限”等列，并保留为岗位级官方资格证据；
- 学生发布门禁只在 `official_attachment_row` 范围内读取该行保留的资格原文，用于识别明确的多年工作经验条件；
- 专业匹配逻辑不读取整行文本，仍只接受明确专业字段，避免因公告描述或相邻列产生专业误匹配；
- 同一官方岗位行明确要求工作经验且未明确允许应届毕业生时，结果为 `out_of_scope / 需工作经验`，不进入学生端审核候选；
- 已明确“应届毕业生可投递”的同一岗位条件仍保留现有例外规则。

## 本轮官方入口复测

- 自然资源部所属企事业单位公开招聘平台首页：HTTP 200，公开 SPA 与只读 API 可访问；本轮 API 返回的是已截止的 2025 年公告，未产生当前学生端岗位。
- 中国地质调查局招聘 JSON：HTTP 200，动态列表可访问；是否存在当前可发布岗位仍须由服务器 Worker 的详情和附件证据复测决定。
- 中国地震局 2027 年事业单位公告：HTTP 200。已审核的 70 条地学岗位将于 `2026-10-10` 开放报名，当前只能作为“即将开放”信息，不能计为在招岗位。
- 中煤地质集团 2026 年成熟人才招聘公告：HTTP 200，附件仍处于私有待审核状态。该公告不因属于地质央企或含地质关键词自动作为学生岗位发布。

上述复测只记录官方来源状态；不会将目录页、历史公告、成熟人才公告或线索页面伪装成可投递的地学岗位。
