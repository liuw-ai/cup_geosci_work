# Phase 55: 国聘动态来源生产切换

本阶段把中国冶金地质总局在国聘公开校园招聘系统中的动态岗位来源切换为生产来源，并修复质量报告在容器重建后的回归夹具漂移。

## 交付范围

- 服务器浏览器独立完成 8 页分页扫描。
- 146/146 条岗位详情成功解析，保留官方详情证据 URL。
- 仅在完整扫描通过后执行原子同步；动态来源启用，旧快照标记为 `superseded`。
- 省级来源质量夹具通过 Compose 只读挂载进入 `web` 和 `worker`，容器重建后仍可执行覆盖率报告。

`audit`、`coverage --record` 和 `worker-health` 均已在服务器复核通过。中石化捕获过期、SLB 详情预算不足等来源故障继续按故障状态展示，不转换成“无岗位”。

本阶段不代表全国国内岗位扩容已完成；公务员当年度职位表仍为 0，三桶油下属单位和省级来源矩阵仍是下一阶段重点。
