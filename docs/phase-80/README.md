# Phase 80 官方 DOCX 附件解析

本阶段补齐官方招聘附件流水线对 Word 文档的处理能力。此前系统已经声明支持 `.docx`，但服务器镜像未安装 `python-docx`，且解析器只读取段落、不读取岗位表格，导致正式岗位附件可能被跳过。

## 变更

- 固定加入 `python-docx==1.1.2` 运行依赖。
- Word 表格按表头和数据行提取，保存表名、行号、单元格、原始行文本和高置信度标记。
- 表头重复时保留 `#2` 等后缀，避免岗位字段互相覆盖。
- 没有表格的公告仍使用段落解析，并保留原有私有复核门禁。
- 不改变学生端发布规则：官方公告、附件哈希、岗位专业、学历、地点、人数和截止日期仍需核验。

## 本阶段不做的事

- 不把解析成功自动等同于岗位可发布。
- 不把历史附件导入为当前在招。
- 不绕过 robots、登录、验证码或访问策略限制。
