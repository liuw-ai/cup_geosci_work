# Phase 82 动态浏览器运行时限

本阶段修复生产运行中的一个实际风险：国聘/CMGB 动态详情采集逐条打开官方详情页，单个页面或浏览器连接异常时可能长期停在 `capturing`，阻塞后续每日采集。旧成功快照必须继续保留，不能因一次失败被清空。

变更：

- CMGB 浏览器 worker 增加单次捕获总时限，默认 1800 秒；
- 超时按失败捕获处理，写入失败原因和 heartbeat，不替换上一次成功清单；
- `CMGB_BROWSER_CAPTURE_TIMEOUT_SECONDS=0` 可在受控调试环境关闭，但生产不建议关闭；
- 只限制运行时间，不绕过 robots、验证码、登录或访问策略；
- 采集成功仍必须满足分页完整、详情成功率和岗位级专业门禁，才可能进入发布流程。
