# Phase 3 本地治理验收记录

日期：2026-10-17  
逻辑基线：`phase532-logical-phase1`
范围：仅本地代码、隔离数据库、测试和审计；没有服务器部署、容器重启或生产自动化运行。

## 已完成

1. **Phase 3 字段回填与历史撤回审计**

   - `jobs` 增加并回填来源等级、来源可用状态、学生端层级、官方公告/申请/岗位表链接、官方核验时间、无截止日期 90 天清理日期等独立字段。
   - `phase3_withdrawal_audits` 保存 3,947 条逐岗位审计记录。
   - 704 条历史撤回的当前数据库结果为：51 条有截止日期已过证据；653 条来源新鲜度、清单暂缺、捕获失败等非撤回理由已恢复为可继续审阅的状态。
   - 官方取消、关闭、替换仅接受明确官方证据；当前数据没有把候选文本升级为正式撤回。

2. **生命周期门禁**

   - 30 小时新鲜度、一次扫描缺失、台账为空、网络/robots/403/结构变化和附件哈希变化不再改变学生端可见性或岗位状态。
   - `withdrawn` 只接受专业明确不匹配、截止日期已过、官方明确取消/关闭/替换。
   - 无截止日期按北京时间发布日期或首次官方证据时间加 90 个自然日计算。

3. **`superseded` 历史快照语义**

   - 增加 successor、原因和时间字段；旧事件中的 successor 关系已在本地回填。
   - 学生端查询显式排除 `superseded`，它不是 `withdrawn`，无 successor 的记录只进入人工审阅。

4. **学生端四级层级**

   - `exact_match`、`broad_geoscience_match`、`incomplete_but_basic_match`、`source_unavailable` 已成为可查询字段并有独立中文标签。
   - “来源暂时不可用”保留历史官方链接和最近核验信息，不等于官方取消。
   - “岗位表链接”与报名/官方详情链接分开显示；第三方链接不会成为申请链接。

5. **第三方职位表候选流程**

   - 中公、粉笔、华图、公考雷达、公考资讯网均登记为 B 级 `batch_candidate_allowed`。
   - 新增独立 `data/third_party_table_adapters.json` 和链接发现器：汇总页 → 表格下载链接 → 哈希/大小/格式校验 → 表格解析 → 私有候选 → 官方 URL 回溯/人工核验 → 才能发布。
   - 当前适配器不会伪造具体下载地址，也不会绕过登录、验证码或 robots；未找到官方 URL 的候选永不进入学生端。

6. **三桶油组织目录结构**

   - 64 个目录单位全部能与组织登记表名称精确匹配。
   - 目录对外输出规范化 `organization_role`：集团、运营公司、地区分公司、研究院、内部服务单位等；旧 `role` 仅保留兼容导入。
   - 单位名称审计报告当前 `name_unverified_unit_count=0`；入口是否可自动采集仍独立由频道核验状态决定，不能由名称匹配推导。

7. **部署与发布边界**

   - 新增唯一生产入口 `deploy/compose.yaml`，路径已按 Compose 所在目录修正。
   - 生成 `docs/current/phase3-release-manifest.json`，绑定 Git、Compose、配置登记、镜像 digest、策略版本、Schema、Phase 532 备份和本地数据库/备份 SHA-256。
   - Manifest 明确 `production_deployment=not_performed`，工作树有未提交改动，因此不能作为服务器发布包。

8. **测试隔离与契约修复**

   - 测试默认使用临时 `APP_DATA_DIR` 和临时数据库；不再写入 `runtime/job_hub.sqlite3`。
   - 浏览器镜像测试改为验证正式 Dockerfile/Compose，不再依赖已归档 overlay。
   - 最新全量结果：`1045 passed, 4 skipped, 1 warning`。

## 尚不能宣称已完成的边界

- 五个第三方网站的真实页面可能需要人工登录、验证码或当前网络许可；本地适配器已完成，但本轮没有把不可审计的猜测 URL 当成真实批量结果。
- 64 个单位的名称已与当前组织登记表精确对照，但每个下属单位的独立招聘入口/工商证据仍必须按频道逐项补证；名称匹配不代表入口可采集。
- `deploy/compose.yaml` 和 Manifest 仅是本地候选发布结构；须经用户本地审阅、提交干净 Git、生成最终备份后，才可能进入服务器流程。

## 用户确认门禁
